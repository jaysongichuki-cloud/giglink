# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-05-17

### Added

- GigLink MVP: browse, search, post, edit, and delete gigs
- Apply for gigs and track applications on a protected dashboard
- Firebase Google and GitHub social authentication
- JSON Server persistence (no browser localStorage)
- Responsive Tailwind UI for mobile and desktop
- Vitest test suite with 30%+ coverage threshold
- GitHub Actions CI and Vercel deployment workflow
- Semantic version **v1.0.0** initial release
